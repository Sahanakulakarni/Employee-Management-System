# Employee Management System

A simple Employee Management System developed using Java.

## Features

* Add Employee
* View Employees
* Search Employee
* Update Employee
* Delete Employee
* Exit

## Technologies Used

* Java
* Eclipse IDE
* ArrayList
* Scanner

## Project Structure

```text
EmployeeManagementSystem
└── src
    └── employee
        ├── Employee.java
        └── EmployeeManagementSystem.java
```

## How to Run

1. Open the project in Eclipse.
2. Open `EmployeeManagementSystem.java`.
3. Run it as a Java Application.
4. Select an option from the menu.
